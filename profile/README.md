## 先搞清楚：香港機房的線路到底有幾種？

選香港機房，線路是核心中的核心。線路不對，其他配置再好也是白費。

目前市面上的香港 VPS 線路，主要分以下幾類：

**CN2 / CN2 GIA**：中國電信的精品網絡，對大陸三網（電信、聯通、移動）都有不同程度的優化。CN2 GIA 是其中最高端的等級，延遲最穩，丟包率最低，但帶寬成本相對較貴，給的口徑通常比較小。

**CMI（CMIN2）**：中國移動的國際網絡，2022 年後越來越受重視。三網走移動回程，延迟表現良好，帶寬通常比 CN2 更寬裕，性價比更高。

**CU2（AS9929）**：中國聯通的精品線路，聯通用戶體驗尤其好，三網均有優化。

**住宅 ISP IP**：這是近幾年新冒出來的需求方向——不只是機房 IP，而是香港本土寬帶運營商（比如 HGC、iCable）的住宅家寬 IP。這類 IP 對香港本土服務（TVB、Cityline、Netflix 港區等）的解鎖能力最強，而且 IP 質量更接近真實用戶，不容易被平台識別為數據中心 IP。

搞明白這幾個概念，選機房就有方向了。接下來分場景說事。
